\# SnowDesk ❄️



A zero-dependency, \*\*60 FPS\*\* interactive winter desktop overlay for Windows 10/11. Built purely with Python's standard library (`tkinter` + `ctypes` Win32/GDI+ + `winmm` + `winsound`) so it runs smoothly without `pip install` or unsigned `.pyd` extensions.



\## Installation \& Quick Start (Zero Dependencies)



No `pip install` required!



1\. Download \*\*`SnowDesk-v1.0.0.zip`\*\* from \[\*\*Releases\*\*](https://github.com/orhandogankaplan/SnowDesk/releases) (or click \*\*Code → Download ZIP\*\*).

2\. Make sure \*\*Python 3.10+\*\* is installed on Windows (\[python.org/downloads](https://www.python.org/downloads/)).

3\. Extract the ZIP folder and double-click \*\*`SnowDesk.vbs`\*\* (runs silently in the background) or \*\*`run.bat`\*\* (or run `py main.py` in terminal).

4\. Press \*\*`F10`\*\* anytime to exit SnowDesk, or \*\*`F12`\*\* to toggle Windows auto-startup.



> \*\*Optional (Standalone `.exe`):\*\* Run `build\_exe.bat` to package SnowDesk with PyInstaller into `dist\\SnowDesk\\SnowDesk.exe`.

| Cycle Theme (`Classic` / `Aurora` / `Cyber` / `Gold`) | \*\*`F1`\*\* |

| Toggle Aurora Borealis | \*\*`F3`\*\* |

| Toggle Winter Sound Effects | \*\*`F4`\*\* |

| Summon Illustrated Santa \& Reindeer Sleigh | \*\*`F5`\*\* |

| Cycle Snow Density (`Gentle` / `Cozy` / `Blizzard`) | \*\*`F6`\*\* |

| Toggle Window Fairy Lights | \*\*`F7`\*\* |

| Sweep Snow with Yellow Snowplow | \*\*`F8`\*\* or \*\*`Ctrl + Shift + C`\*\* |

| Launch New Year Fireworks | \*\*`Ctrl + Shift + F`\*\* |

| Pause / Resume | \*\*`F9`\*\* |

| Exit SnowDesk | \*\*`F10`\*\* |

| Reels Demo Mode (9s showcase) | \*\*`F11`\*\* |

| Toggle Windows Auto-Startup | \*\*`F12`\*\* |
