\# SnowDesk ❄️



A zero-dependency, \*\*60 FPS\*\* interactive winter desktop overlay for Windows 10/11. Built purely with Python's standard library (`tkinter` + `ctypes` Win32/GDI+ + `winmm` + `winsound`) so it runs smoothly without `pip install` or unsigned `.pyd`/`.exe` files blocked by Windows Smart App Control.



\## Installation \& Quick Start (Zero Dependencies)



No `pip install` required!



1\. Download \*\*`SnowDesk-v1.0.0.zip`\*\* from \[\*\*Releases\*\*](https://github.com/orhandogankaplan/SnowDesk/releases) (or click \*\*Code → Download ZIP\*\*).

2\. Make sure \*\*Python 3.10+\*\* is installed on Windows (\[python.org/downloads](https://www.python.org/downloads/)).

3\. Extract the ZIP folder, open \*\*CMD / PowerShell\*\* inside the extracted folder, and run:



&#x20;   py main.py



\*(Or to run silently in the background without a console window: `start "" pyw main.py`)\*



4\. \*\*If you prefer double-clicking `SnowDesk.vbs` or `run.bat`:\*\* Right-click the downloaded ZIP \*\*before extracting\*\* → \*\*Properties\*\* → check \*\*Unblock\*\* → \*\*Apply\*\*, then extract and double-click `SnowDesk.vbs`.

5\. Press \*\*`F10`\*\* anytime to exit SnowDesk, or \*\*`F12`\*\* to toggle Windows auto-startup.



\## Features



\- \*\*Music Bass-Reactive Snow Bounce:\*\* Reads real-time Windows system audio output so accumulated snowdrifts visibly ripple and launch snow granules into the air to the beat.

\- \*\*True Zero-Glue Window Physics:\*\* Snow piles onto open windows and the taskbar, flows onto neighboring windows when slid sideways, sheds naturally when shrinking or minimizing windows, and breaks off icicles when shaken.

\- \*\*Interactive Winter World:\*\* Drag \& toss eye-tracking snowmen, roll/stack snowballs, deflect snowballs thrown by snowmen, watch the mini window skier jump between windows, or clear everything with the yellow snowplow (`F8`).

\- \*\*Real-Time Sensors \& Effects:\*\* Microphone blow detection, keystroke micro-quake, window shake snowglobe vortex, thermal cursor water droplets, CPU/RAM fractal corner ice cracks, live Open-Meteo wind sync, and battery-reactive streetlamp.

\- \*\*Santa Sleigh \& Now-Playing Banner (`F5`):\*\* Illustrated Santa \& reindeer sleigh flies across the sky with a banner showing your currently playing Spotify/YouTube/VLC track.

\- \*\*Aurora Borealis, Themes (`F1` / `F3`), \& New Year Fireworks (`Ctrl + Shift + F`):\*\* Switch between `Classic`, `Aurora`, `Cyber`, and `Gold` themes, with a glassmorphism Tech HUD (`F2`) and New Year countdown cabin sign.
